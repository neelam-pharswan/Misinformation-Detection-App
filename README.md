# 🧠 Misinformation Detection App

A professional fake news detection web application built using **DistilBERT**, **PyTorch**, and **Streamlit**.

The model analyzes news headlines, claims, and article snippets to classify them as:

- ✅ Real News
- ⚠️ Fake News
